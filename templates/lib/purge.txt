# File purge manifest — paths shiploop USED to install and no longer ships.
#
# Format: one workspace-relative path per non-comment line. A trailing `/` marks a
# directory (removed recursively). scaffold.sh deletes every listed path from the
# workspace on any writer run (fresh scaffold, `--component X`, `/shiploop:update`)
# and merely WARNS about them under standalone `--verify` (which never writes).
#
# This is how an already-installed fleet sheds a retired file. When you DELETE a
# template that earlier versions shipped, ADD its installed path here. When you MOVE
# one, use relocations.txt instead (warn-only, from → to).
#
# Purge is unconditional: a listed path is removed even if locally edited. Only list
# mechanism files shiploop owns — never operator data (workspace.sh, queue/, governor/
# preferences, seed CLAUDE.md).
