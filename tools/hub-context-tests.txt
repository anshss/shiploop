# Tests that assert on the HUB itself — scaffold.sh, VERSION, templates/lib/*, purge.txt,
# seed-hashes.txt — rather than on an installed workspace mechanism.
#
# They resolve the hub as `$DIR/../../..` and `exit 77` when that is not a hub checkout.
# `scaffold-and-test` copies the suite into a throwaway WORKSPACE, so that path is the
# workspace root and every test here skips — and CI counts 77 as a skip, not a failure.
# The result was silent: these ran green locally and never executed in CI at all.
#
# The `hub-context-tests` job runs this list from the checkout, where the path resolves,
# and treats a 77 as a HARD FAILURE. `scaffold-and-test` cross-checks its own skip list
# against this file, so a new hub-context test that isn't listed here fails CI rather than
# quietly never running.
#
# One test name per non-comment line (no .sh suffix).
#
# A leading `!` QUARANTINES a test: it still counts as "accounted for" by the
# scaffold-and-test cross-check (so it is never silently unlisted), but the
# hub-context-tests job reports it instead of failing on it. Quarantine is for a test
# that is broken independently of the change at hand — it must carry a reason and a
# ticket, and it is a debt marker, not a parking space.
